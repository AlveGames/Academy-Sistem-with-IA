1.1Cómo es un buen prompt

Un prompt es una orden de trabajo. Si la orden es vaga, la IA adivina; si es precisa, entrega lo que necesitas. Todos los prompts de esta guía tienen las mismas partes:

PartePregunta que respondeEjemplo
Contexto¿En qué proyecto estamos?«Proyecto Django sistema_academico con las apps core y academico…»
Tarea¿Qué quiero ahora? (una sola cosa)«Crea el CRUD de Estudiante con vistas basadas en clases»
Requisitos¿Qué debe tener exactamente?«Paginado de 10, validar cédula de 10 números…»
Restricciones¿Qué NO debe hacer?«No cambies los modelos. No uses def para vistas»
Entrega¿En qué forma lo quiero?«Archivo por archivo, con la ruta y si reemplazo o agrego»
Verificación¿Cómo sé que funciona?«Dime qué URL abrir y qué debo ver»
Tres reglas de oro
  1. Un paso a la vez. Un prompt gigante produce código gigante que no entiendes. Esta guía divide cada CRUD en 5 prompts pequeños.
  2. Nunca pegues sin leer. Si no entiendes una línea, usa el prompt «Explícame» (1.3). En la evaluación te preguntarán por tu código.
  3. Prueba y guarda. Después de cada prueba exitosa: git add . y git commit -m "...". Si el siguiente paso sale mal, vuelves atrás con un comando.

Tres decisiones de diseño (y por qué)
  1. «Diurna / nocturna» es un dato de la Sección (campo jornada con choices), no una tabla aparte: solo hay dos valores fijos. La sección junta curso + periodo + profesor + jornada + paralelo + cupo.
  2. Matrícula es una tabla intermedia escrita por nosotros. Un estudiante toma muchas secciones y una sección tiene muchos estudiantes (N:M), pero necesitamos guardar datos de esa unión (la fecha y luego sus notas). Por eso ManyToManyField(..., through="Matricula").
  3. Nota es 1:1 con Matrícula y guarda promedio y estado. Se calculan en save(); se guardan (aunque se podrían calcular) para poder filtrar y exportar «todos los reprobados» con una consulta simple.

NOTA_MAXIMA = Decimal("100")
VALIDAR_NOTA = [MinValueValidator(Decimal("0")), MaxValueValidator(NOTA_MAXIMA)]   # 0 ≤ nota ≤ 100

    NOCTURNA = "nocturna", "Nocturna"


class EstadoNota(models.TextChoices):

# =====================================================================
# 1. ESTRUCTURA: Universidad 1:N Facultad 1:N Carrera
# =====================================================================
class Universidad(ModeloBase):
    nombre = models.CharField(max_length=150, unique=True)
    siglas = models.CharField(max_length=20)                         # Ej: UG, ESPOL
    ciudad = models.CharField(max_length=80)
    logo = models.ImageField(upload_to="universidades/", blank=True)  # sale en los comprobantes PDF

    class Meta:
        verbose_name = "Universidad"
        verbose_name_plural = "Universidades"
        ordering = ["nombre"]

    def __str__(self):
        return self.siglas


class Facultad(ModeloBase):
    universidad = models.ForeignKey(Universidad, on_delete=models.PROTECT, related_name="facultades")   # 1:N
    nombre = models.CharField(max_length=150)
    decano = models.CharField(max_length=150, blank=True)

    class Meta:
        verbose_name = "Facultad"
        verbose_name_plural = "Facultades"
        ordering = ["nombre"]
        constraints = [   # el mismo nombre puede existir en otra universidad, pero no dos veces en la misma
            models.UniqueConstraint(fields=["universidad", "nombre"], name="facultad_unica_por_universidad"),
        ]

    def __str__(self):
        return self.nombre


class Carrera(ModeloBase):
    facultad = models.ForeignKey(Facultad, on_delete=models.PROTECT, related_name="carreras")   # 1:N
    codigo = models.CharField("Código", max_length=10, unique=True)   # Ej: SIS
    nombre = models.CharField(max_length=150)
    duracion_semestres = models.PositiveSmallIntegerField("Duración (semestres)", default=8)

    class Meta:
        verbose_name = "Carrera"
        verbose_name_plural = "Carreras"
        ordering = ["nombre"]

    def __str__(self):
        return self.nombre


# =====================================================================
# 2. CATÁLOGO: Semestre, Periodo y Curso
# =====================================================================
class Semestre(ModeloBase):
    numero = models.PositiveSmallIntegerField(unique=True, validators=[MinValueValidator(1), MaxValueValidator(12)])
    nombre = models.CharField(max_length=30)                          # Ej: Primer semestre

    class Meta:
        verbose_name = "Semestre"
        verbose_name_plural = "Semestres"
        ordering = ["numero"]

    def __str__(self):
        return self.nombre


class Periodo(ModeloBase):
    nombre = models.CharField(max_length=20, unique=True)             # Ej: 2026-1
    fecha_inicio = models.DateField("Fecha de inicio")
    fecha_fin = models.DateField("Fecha de fin")
    activo = models.BooleanField(default=False)                       # el periodo en el que se matricula

    class Meta:
        verbose_name = "Periodo"
        verbose_name_plural = "Periodos"
        ordering = ["-fecha_inicio"]                                  # el más reciente primero

    def __str__(self):
        return self.nombre

    def clean(self):                                                  # validación de VARIOS campos juntos
        if self.fecha_inicio and self.fecha_fin and self.fecha_fin <= self.fecha_inicio:
            raise ValidationError({"fecha_fin": "La fecha de fin debe ser posterior a la de inicio."})


class Curso(ModeloBase):                                              # la asignatura (materia)
    carrera = models.ForeignKey(Carrera, on_delete=models.PROTECT, related_name="cursos")      # 1:N
    semestre = models.ForeignKey(Semestre, on_delete=models.PROTECT, related_name="cursos")    # 1:N
    codigo = models.CharField("Código", max_length=12, unique=True)  # Ej: SIS-101
    nombre = models.CharField(max_length=150)
    creditos = models.PositiveSmallIntegerField("Créditos", default=3)

    class Meta:
        verbose_name = "Curso"
        verbose_name_plural = "Cursos"
        ordering = ["carrera", "semestre__numero", "nombre"]

    def __str__(self):
        return f"{self.codigo} · {self.nombre}"


# =====================================================================
# 3. PERSONAS: Profesor y Estudiante
# =====================================================================
class Profesor(ModeloBase):
    cedula = models.CharField("Cédula", max_length=10, unique=True)
    nombres = models.CharField(max_length=80)
    apellidos = models.CharField(max_length=80)
    email = models.EmailField("Correo", blank=True)
    titulo = models.CharField("Título", max_length=120, blank=True)  # Ej: Mg. en Software

    class Meta:
        verbose_name = "Profesor"

class FiltroCamposMixin:
    """Componente 1: filtros + selección de columnas. Se usa con ListView."""
    filtro_form_class = None          # formulario de filtros (Form normal, todos los campos opcionales)
    campos_disponibles = []           # [("ruta__del__campo", "Título"), ...]
    campos_por_defecto = []           # rutas que se marcan si el usuario no elige

    def filtrar(self, queryset, datos):
        """Cada vista lo sobrescribe: recibe cleaned_data y devuelve el queryset filtrado."""
        return queryset

    def get_queryset(self):
        queryset = super().get_queryset()
        self.filtro_form = self.filtro_form_class(self.request.GET or None) if self.filtro_form_class else None
        if self.filtro_form is not None and self.filtro_form.is_valid():
            queryset = self.filtrar(queryset, self.filtro_form.cleaned_data)
        return queryset

    def get_campos_seleccionados(self):
        titulos = dict(self.campos_disponibles)
        elegidos = [c for c in self.request.GET.getlist("campos") if c in titulos]   # solo rutas permitidas
        elegidos = elegidos or self.campos_por_defecto or list(titulos)
        return [(c, titulos[c]) for c in elegidos]

    def get_context_data(self, **kwargs):
        contexto = super().get_context_data(**kwargs)
        campos = self.get_campos_seleccionados()
        contexto["filtro_form"] = self.filtro_form
        contexto["campos_disponibles"] = self.campos_disponibles
        contexto["campos_seleccionados"] = [c for c, _ in campos]
        contexto["encabezados"] = [t for _, t in campos]
        contexto["filas"] = [(obj, [valor_campo(obj, c) for c, _ in campos]) for obj in contexto["object_list"]]
        consulta = self.request.GET.copy()                         # la consulta actual SIN page ni exportar
        consulta.pop("page", None)
        consulta.pop("exportar", None)
        contexto["consulta"] = consulta.urlencode()
        return contexto

def enlazar_archivos(uri, rel):
    """xhtml2pdf necesita rutas del DISCO para imágenes: /media/x.png → C:/.../media/x.png"""
    if uri.startswith(settings.MEDIA_URL):
        return str(settings.MEDIA_ROOT / uri.replace(settings.MEDIA_URL, ""))
    if uri.startswith(settings.STATIC_URL):
        return str(settings.BASE_DIR / "static" / uri.replace(settings.STATIC_URL, ""))
    return uri


def render_pdf(template, contexto, nombre_archivo, descargar=False):
    html = render_to_string(template, contexto)                    # 1. template + datos → HTML
    buffer = BytesIO()
    resultado = pisa.CreatePDF(html, dest=buffer, link_callback=enlazar_archivos)   # 2. HTML → PDF
    if resultado.err:
        return HttpResponse("Error al generar el PDF", status=500)
    respuesta = HttpResponse(buffer.getvalue(), content_type="application/pdf")
    modo = "attachment" if descargar else "inline"                 # inline = se abre en el navegador
    respuesta["Content-Disposition"] = f'{modo}; filename="{nombre_archivo}.pdf"'
    return respuesta
